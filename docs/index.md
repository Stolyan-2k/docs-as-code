# Моя документация

Это мой первый документационный проект в подходе Docs as Code.

Автор: **Yan Komarevtsev**.

## О проекте

Документация хранится в Git и создаётся с помощью MkDocs.
Практическая работа показывает полный путь от Markdown-файла до работающего сайта.
История коммитов помогает отслеживать изменения, а GitHub хранит исходники проекта.

## Возможности

- **Markdown** — простой формат для написания документации.
- **Git** — история изменений и управление версиями.
- **GitHub** — хранение репозитория и совместная работа.
- **MkDocs** — сборка и локальный просмотр сайта.
- **Read the Docs** — встроенная тема с навигацией.
- **Поиск** — встроенный плагин для поиска по русскоязычной документации.

## Как обновить документацию

1. Изменить файл `docs/index.md`.
2. Запустить `mkdocs serve` и проверить результат.
3. Выполнить `mkdocs build --strict` для проверки сборки.
4. Сохранить изменения коммитом и отправить их в GitHub.
